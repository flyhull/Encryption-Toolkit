This repository provides:

Libraries to:
a) Encrypt and decrypt using a key based on the current time, and a preshared date or timestamp and a preshared passphrase
b) Encrypt and decrypt using a one-time pad generated by encrypting the pixels in a preshared image using the method above
c) Obsfucate padded cyphertext in a new or pre-existing image and recover it afterwards and 
d) Recover a decrypted file's original extension using Mime Detective

Sample applications:
a) A demo
b) A password vault
